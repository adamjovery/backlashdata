# backlashdata
Replication dataset from Colantone & Stanig 2018 - "The Trade Origins of Economic Nationalism: Import Competition and Voting Behavior in Western Europe" & a Panel dataset across 31 European countries over the period between 2013-2024. This includes the code required to recreate the results of my regression analyses and the appendices for both the panel dataset and the replication dataset performed in my dissertation:

“Which aspect of globalisation has caused the greatest backlash in Europe, and does higher social protection expenditure moderate the backlash caused?”

This also includes the code used to create the dataset once the data has been downloaded from various sources (World Bank, Timbro, etc)
Use of replication dataset must properly cite: Stanig, P. & Colantone, I. (2018) Replication Data for: The Trade Origins of Economic Nationalism: Import Competition and Voting Behavior in Western Europe. doi:10.7910/DVN/NRAQRH.
